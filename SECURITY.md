# Security

Use [GitHub private vulnerability reporting](https://github.com/WyrchikDev/disecta/security/advisories/new) when enabled. If private reporting is unavailable, open a GitHub issue asking the maintainers for a private reporting channel. Keep vulnerability details and sensitive input files out of the public issue.

Include the DISECTA commit, operating system, exact command, observed behavior, and a minimal reproducible input when sharing privately. DISECTA treats executable files as untrusted data and performs static analysis.
